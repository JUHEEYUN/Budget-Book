# 우리 가계부 — 최종본 (2026-10-27)

부부가 함께 쓰는 가계부 앱이에요. 화면은 **GitHub Pages**(아이폰 홈 화면 앱), 데이터는 **구글 시트 + Apps Script**에 있어요.
이 폴더만 있으면 처음부터 다시 설치하거나, 다른 사람(또는 AI)에게 넘겨도 구조를 이해할 수 있게 정리했어요.

---

## 폴더 안 파일

| 파일 | 어디에 넣나 | 하는 일 |
|---|---|---|
| `index.html` | **GitHub 저장소** | 앱 화면 전체 (HTML·CSS·JS 한 파일) |
| `manifest.json` | GitHub 저장소 | 홈 화면 앱 이름·아이콘 정보 |
| `sw.js` | GitHub 저장소 | 화면 파일을 폰에 담아 빨리 열리게 함 |
| `icons/` | GitHub 저장소 | 홈 화면 아이콘 3개 |
| `Code.gs` | **구글 Apps Script** (GitHub에 올리지 않음) | 시트 읽기·쓰기 API, 계산용 데이터 정리 |
| `README.md` | 보관용 | 이 설명서 |

> `manifest.json`, `sw.js`, `icons/`는 이번에 바뀌지 않았어요. 이미 GitHub에 올라가 있으면 그대로 두면 돼요.

---

## 넣을 때 꼭 바꿔야 하는 두 줄

**Code.gs 맨 위** — 두 분만 아는 비밀 키 (지금 쓰는 값 그대로)
```js
var API_KEY = '여기에-비밀키를-넣으세요';
```

**index.html 위쪽** — Apps Script 웹 앱 주소 (`…/exec`)
```js
var API_URL = '';
```
비밀 키는 index.html에 적지 않아요. 앱을 처음 열 때 폰에서 한 번 입력하면 폰에 저장돼요.

---

## 업데이트 순서 (이미 쓰고 있을 때)

1. **Code.gs**: Apps Script에서 전체 바꿔 붙여넣기 → `API_KEY` 넣기 → 저장 →
   **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** (이걸 해야 반영돼요. 이렇게 하면 주소도 그대로)
2. **index.html**: `API_URL` 넣기 → GitHub 저장소에 업로드(Add file → Upload files → Commit)
3. 1~2분 뒤 폰에서 앱을 껐다 켜기 (한 번에 안 바뀌면 한 번 더)

비밀 키를 그대로 두면 폰에서 다시 입력할 필요 없어요.

## 처음 설치할 때

1. 구글 시트 → 확장 프로그램 → Apps Script → `Code.gs` 붙여넣기, `API_KEY` 정하기 → 저장
2. **배포 → 새 배포 → 웹 앱** / 실행: **나** / 액세스: **모든 사용자** → 주소(`/exec`) 복사
3. `index.html`의 `API_URL`에 주소 넣기
4. GitHub 새 저장소(Public) → `index.html`, `manifest.json`, `sw.js`, `icons/` 업로드 → **Settings → Pages → main / (root)**
5. 아이폰 **사파리**로 `https://아이디.github.io/저장소이름/` → 공유 → **홈 화면에 추가** → 앱 안에서 비밀 키 입력

## 앱 구성 (탭)

- **홈**: 이번 달 남은 돈, 이 속도면 월말에 얼마, 통장 잔고(카드 결제 시차 반영), 카드 실적, 고정비 요약, 카드대금
- **기록**: 목록 / 달력. 아래 입력창에 카드 문자 붙여넣기 또는 "점심 12000", 여러 줄 메모 한 번에 등록
- **고정비**: 아직 안 낸 것 위 / 낸 것 접기. 체크하면 지출 기록까지 생성. 아래 비정기(변동)
- **저축**: 비상금·적금·투자 배분과 잔고, 이번 달 이체, 올해 누적
- **정산**: 누가 얼마 냈나, 카테고리별(누르면 내역), 카드별(누르면 내역), 월별 추이, **연말정산**

## 연말정산 (정산 탭 맨 아래)

- **내년 초에 돌려받을 돈 (두 분 합계)** — 카드 + 보험·기부·월세(+의료비)
- **몰아 쓰기 비교** — "한 사람 카드로 몰아 썼다면 약 ○만원 더"
  (연봉의 25%까지 쓴 카드값은 혜택이 없고 이 구간이 사람마다 따로라서, 보통 한 사람에게 몰아 쓰는 게 유리)
- **다음 결제는 ○○ 카드** — 10만원 쓸 때마다 더 받는 돈 기준 추천
- 사람별: 혜택 받는 중 / ○○만 더 쓰면 혜택 시작
- **카드 말고 다른 혜택**: 보험료(1인 100만원까지 약 13%), 기부금(약 16%), 월세(세대주, 시·구 지원금 뺀 실제 낸 돈의 약 17%), 의료비(실비 뺀 금액이 연봉 3% 근처일 때만 표시)
- **설정**(정산 탭 연말정산 카드의 [설정] 또는 ⚙️ → 연말정산 설정): 세전 연봉(만원), 카드 명의, 세대주, 월세 지원금(한 달)
- 모든 금액은 **어림값**이에요. 정확한 건 11월 홈택스 "연말정산 미리보기"로 확인

### 기록 요령 (연말정산이 맞게 계산되려면)
- 보험료 → 카테고리 **보험비**, 누구 지출 = 보험 계약자
- 기부 → 내용에 기부처 이름 또는 "기부/후원" (기아대책·유니세프·월드비전 등 자동 인식)
- 실비 받은 돈 → 수입으로, 내용에 **"실비"**
- 해외 결제(GPT·클로드 등), 공과금·통신·보험·대출·월세 카드 결제는 카드 혜택에서 자동 제외

## 고칠 일이 생기면 (코드 위치)

| 바꾸고 싶은 것 | 파일 · 찾을 이름 |
|---|---|
| 카드 목록·종류(신용/체크) | index.html · `PAYS` (`type: credit/check/none`) |
| 카테고리 | index.html · `BUCKETS` **그리고** Code.gs · `CATS_SPEND` (둘 다 같이) |
| 가맹점 → 카테고리 자동 분류 | index.html · `RULES` |
| 카드 공제 규칙(공제율·한도·연도별) | index.html · `DED_RULES` (2026, 2027 따로) |
| 보험·기부·월세·의료비 규칙 | index.html · `DED_ETC` |
| 연말정산 표시 시작 연도 | index.html · `DED_START`, `DED_FULL` |
| 공제 제외·대중교통·문화 판별 단어 | Code.gs · `DED_EXCL_TEXT`, `DED_NOT_TRANSIT`, `DED_CULTURE`, `DED_DONATION` |
| 돌려받는 돈 어림 세율 | index.html · `taxRate` |

### 데이터 구조 (구글 시트 탭)
- **거래**: id, 기록시각, 날짜, 구분(지출/수입/저축), 금액, 내용, 카테고리, 결제수단, 사람(A=아내/B=남편), 메모, 실적제외, 주머니, 원문
- **설정**: 키/값 (nameA, nameB, salA, salB, own_카드id, dedHead, rentSub, 저축 배분·시작 잔고, 카드 실적 목표 등)
- **고정비**, **학습**(가맹점→카테고리, 카드→사람), **납부**(월별 고정비 체크)
