# 우리 가계부 — 홈 화면 앱(PWA) 설치 안내

화면은 GitHub Pages에 올리고, 구글 시트와 Code.gs는 그대로 데이터 창고로 씁니다.
순서대로 따라 하면 30분 안에 끝나요. 기존 시트 데이터는 그대로예요.

## 올릴 파일

```
index.html      ← 앱 화면 (API_URL 한 줄만 바꿈)
manifest.json   ← 앱 이름·아이콘 정보
sw.js           ← 빨리 열리게 화면 파일을 담아두는 파일
icons/          ← 아이콘 3개 (icon-180.png, icon-192.png, icon-512.png)
```

`Code.gs`는 GitHub에 올리지 않아요. 구글 Apps Script에만 넣습니다.

---

## 1단계 — Code.gs 바꾸고 다시 배포하기

1. 가계부 구글 시트 → **확장 프로그램 → Apps Script**
2. `Code.gs` 내용을 전부 지우고 새 `Code.gs`를 붙여넣기
3. 맨 위 이 줄의 값을 **두 분만 아는 비밀 키**로 바꾸기 (영문·숫자 섞어 12자 이상)
   ```js
   var API_KEY = '여기에-비밀키를-넣으세요';
   ```
4. 💾 저장
5. 오른쪽 위 **배포 → 배포 관리** → 지금 쓰는 배포의 ✏️(수정)
   - 버전: **새 버전**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** ← 꼭 이걸로. "Google 계정이 있는 모든 사용자"면 연결이 안 돼요
   - **배포** 누르기
6. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/……/exec`)을 복사

> 배포 관리에서 '새 버전'으로 고치면 주소가 그대로라서, 지금 쓰는 북마크도 계속 동작해요. 새 앱이 잘 되는 걸 확인한 다음에 지우면 돼요.
> Apps Script 안의 `Index` 파일은 그대로 두세요. 옛 북마크용이에요.

## 2단계 — index.html에 주소 넣기

`index.html`을 메모장이나 VS Code로 열고, 이 줄의 따옴표 안에 6번에서 복사한 주소를 붙여넣기:

```js
var API_URL = '';
```
↓
```js
var API_URL = 'https://script.google.com/macros/s/……/exec';
```

비밀 키는 여기 적지 **않아요**. GitHub에 올라가는 파일은 누구나 볼 수 있기 때문이에요.

## 3단계 — GitHub에 올리기

1. [github.com](https://github.com) 로그인 (없으면 가입)
2. 오른쪽 위 **+ → New repository**
   - Repository name: `ledger` (원하는 이름 아무거나)
   - **Public** 선택 (무료 Pages는 공개 저장소만 돼요)
   - **Create repository**
3. 만들어진 화면에서 **uploading an existing file** 클릭
4. `index.html`, `manifest.json`, `sw.js`, `icons` 폴더를 통째로 끌어다 놓기 → **Commit changes**
5. 저장소 **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / **(root)** → **Save**
6. 1~2분 기다리면 같은 화면 위쪽에 주소가 떠요: `https://아이디.github.io/ledger/`

## 4단계 — 아이폰에 설치 (두 분 다)

1. **사파리**로 위 주소 열기 (크롬 앱 말고 사파리)
2. 아래 **공유 버튼(□↑) → 홈 화면에 추가** → 추가
3. 홈 화면에 생긴 **가계부** 아이콘으로 열기
4. "시트 연결" 화면에 **비밀 키** 입력 → 연결

> 아이폰은 사파리와 홈 화면 앱의 저장 공간이 따로예요. 그래서 비밀 키는 꼭 **홈 화면 아이콘으로 연 앱 안에서** 입력해야 해요.
> 잘 되는 걸 확인했으면 예전 북마크 아이콘은 지워도 돼요.

## 나중에 고칠 때

| 고치는 것 | 하는 방법 |
|---|---|
| 화면 (`index.html`) | GitHub 저장소에서 파일을 다시 올리거나 ✏️로 바로 수정 → 1~2분 뒤 앱을 다시 열면 반영 |
| 시트 쪽 (`Code.gs`) | Apps Script에서 수정·저장 → **배포 관리 → ✏️ → 새 버전 → 배포** (이걸 안 하면 반영 안 돼요) |
| 비밀 키 변경 | `Code.gs`의 `API_KEY` 바꾸고 새 버전 배포 → 앱이 알아서 새 키를 다시 물어봐요 |
| 이 폰에서 키 다시 입력 | 앱 설정(⚙️) 맨 아래 **비밀 키 다시 입력** |

## 알아두면 좋은 것

- **보안**: 저장소는 공개지만 거기엔 화면 코드만 있어요. 가계부 데이터는 구글 시트에 있고, 비밀 키 없이는 읽기·쓰기 모두 안 돼요.
- **속도**: 앱 화면은 바로 뜨고, 숫자는 시트에서 받아오느라 1~2초 걸려요. 다른 사람이 입력한 내용은 12초마다, 그리고 앱으로 돌아올 때마다 새로 받아와요.
- **처음 며칠**: 자주 쓰는 카테고리 순서는 기기에 쌓이는 정보라 새 앱에서 다시 쌓여요.
- **API_URL을 비워두면** 시트 없이 예시 데이터로 움직이는 미리보기 모드가 돼요.

## 연결이 안 될 때

- "비밀 키가 맞지 않아요" → `Code.gs`의 `API_KEY`와 글자 하나까지 같은지, 새 버전으로 배포했는지 확인
- "연결하지 못했어요" → ① `index.html`의 `API_URL`이 `/exec`로 끝나는지 ② 배포 액세스가 **모든 사용자**인지 ③ Code.gs를 고친 뒤 **새 버전**으로 배포했는지 확인
